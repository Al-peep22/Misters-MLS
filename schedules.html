Scheduled shift

Select an employee, then click an available time to create a shift of up to 8 hours, stopping at unavailable time. Shifts must be at least 3 hours. Select a shift to use the controls at its ends.

Export schedule data

Download each CSV file you need. The schedule CSV contains the currently selected week and can be imported into any selected week. Preferences stay saved locally and are not exported.

Each file includes a title, editing notes, and a column guide. Keep the column header row; guide rows are ignored during import. Edit or add data rows, save as CSV, then import the file. Employee IDs connect the employee, availability, time-off, and schedule files; when adding an employee, import the employee file together with any related availability or time-off files. For a schedule import, unlock the selected week first.

Use job titles GSS, GSS_key_holder, or Manager; days sun through sat; times in 24-hour HH:MM format; and time-off dates in YYYY-MM-DD.
